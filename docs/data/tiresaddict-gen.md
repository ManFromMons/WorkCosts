# Tiresaddict generation dump

Free “Make / Model / Generation / Years” JSON from [Tiresaddict car databases](https://tiresaddict.com/help/databases/cars/) (`gen_json.free`). They mark it free to download and without guarantee of fullness.

The file [tiresaddict-gen.json](tiresaddict-gen.json) is **generator input** for [19-car-details-catalogue.md](../features/19-car-details-catalogue.md). The shipping app reads only the generated `WorkCosts.Core/Data/car-details.json`. Do not commit a paid Tiresaddict dump.
