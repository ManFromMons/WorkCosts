# Settings

A **page** (not a GNOME Preferences window). Narrow column (readable width, ~40rem), stacked cards, scroll.

1. **Theme** — Auto / Light / Dark.  
2. **Database** — show file path, selectable text.  
3. **Page cache** — explanation, path, stats, per-domain checkboxes (pages + images sizes), clear selected, option to delete cached images. Clearing cache must **not** delete catalogue products or library photos.
